1. 처리하는 정보

정보용도보관 위치
휴대폰의 통화 녹음·음성 녹음 파일사용자의 Google 드라이브에 백업사용자 본인의 Google 드라이브
녹음 메타데이터(원래 파일명, 녹음 시각, 크기, 길이, 체크섬)폴더 정리, 중복 방지, 재설치 후 복구휴대폰의 앱 전용 저장소, 사용자 드라이브의 정보 파일
Google 계정 식별 정보(이메일, Drive 사용자 ID)백업 위치 확인휴대폰의 앱 전용 저장소

통화 녹음의 원래 파일명에는 상대방의 연락처 이름이나 전화번호가 포함될 수 있습니다. 이 정보는 사용자 본인의 드라이브에 있는 정보 파일에만 보존하며, 드라이브에 올리는 녹음 파일 이름과 앱 로그에는 넣지 않습니다.

2. 전송과 제3자 제공

이 앱에는 별도 서버가 없습니다. 모든 데이터는 휴대폰에서 Google 드라이브 API를 통해 사용자 본인의 드라이브로 직접 전송됩니다. 개발자는 사용자의 녹음이나 정보를 받지 않으며 제3자에게 제공하거나 판매하지 않습니다. 광고·분석 도구를 사용하지 않습니다.

3. Google 사용자 데이터

이 앱은 https://www.googleapis.com/auth/drive.file 권한만 요청합니다. 이 권한으로는 이 앱이 만든 폴더와 파일만 생성·조회·수정할 수 있고, 사용자의 다른 드라이브 파일에는 접근할 수 없습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

인증 토큰은 휴대폰의 Google Play 서비스가 관리하며, 앱은 토큰을 파일이나 백업에 저장하지 않습니다.

4. 보관과 삭제

  • 앱을 삭제하면 휴대폰의 백업 기록이 삭제됩니다. 드라이브에 백업된 파일은 사용자가 직접 지울 때까지 남습니다.
  • 휴대폰에서 녹음을 지워도 드라이브의 백업은 지우지 않습니다. 드라이브에서 지운 파일을 앱이 자동으로 다시 만들지 않습니다.
  • 드라이브 접근 권한은 Google 계정의 서드 파티 연결에서 언제든 해제할 수 있습니다.

5. 문의

이 앱은 개인용으로 만들어졌습니다. 문의는 Google 동의 화면에 표시된 지원 이메일로 해 주세요.

Privacy summary: This app uploads the user's own recordings directly from the phone to the user's own Google Drive using only the drive.file scope (files created by this app). There is no developer server, no sharing with third parties, no ads or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
